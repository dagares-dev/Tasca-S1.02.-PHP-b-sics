# Exercicis PHP

**Descripció**: Exercicis pràctics de PHP variables, tipus de dades, constants, operadors, funcions amb condicionals.

## 🛠 Tecnologies
- Backend: PHP
- Frontend: HTML, CSS

## 🚀 Instal·lació
1. Clonar el repositori: `git clone ...`
2. Instal·lar un servidor local amb PHP (XAMPP, Laragon o MAMP), o executar-ho directament amb la CLI de PHP: `php -S localhost:8000`
3. Obrir el navegador a `http://localhost:8000/nom_del_fitxer.php`

## 📋 Exercicis

| # | Contingut |
|---|---|
| 1 | Variables, tipus de dades, constants i `var_dump()` |
| 2 | Funcions de strings: `strtoupper()`, `strlen()`, `strrev()` i concatenació |
| 3 | Operadors aritmètics (suma, resta, multiplicació, mòdul) i funció amb operació per paràmetre |
| 4 | Funció amb paràmetres per defecte per comptar amb un salt configurable |
| 5 | Funció condicional per calcular el grau d'un/a estudiant segons la nota |
| 6 | Funció amb `rand()` per simular un esdeveniment amb un 50% de probabilitat |
